## P0 mới (đã sửa trong vòng 83)

### P0-1. Độ dài tên trong dir entry tin từ đĩa
- `crates/vifast-fs/src/lib.rs:1294/1478/1874`: `let len = block[off+2] as usize;`
  rồi cắt `block[off+3 .. off+3+len]`. Một byte `len=200` trên đĩa làm panic
  VFS server → mọi IPC sau đó treo.
- Sửa: kiểm tra `len != 0 && len <= MAX_NAME && off+3+len <= BLOCK_SIZE`,
  entry hỏng bị bỏ qua. Test `corrupt_dir_entry_length_does_not_panic`.

### P0-2. Dir size vượt số slot block + bitmap không kiểm biên
- `inode.blocks` là `[u32;12]` nhưng `blocks_used()` tính từ `size` trên đĩa;
  dir size 7000 → index quá biên trong mọi vòng lặp thư mục.
- `mark_free`/`mark_used` ghi `bitmap[block/8]` với block number đọc từ đĩa →
  ghi ra ngoài mảng hàng trăm MB.
- Sửa: `blocks_used()` kẹp theo `MAX_BLOCKS_PER_INODE` **chỉ với INODE_DIR**
  (file lớn dùng `file_block()` hợp lệ), `mark_free`/`mark_used` kiểm tra
  `block < block_count()` và biên bitmap. Test
  `corrupt_dir_size_beyond_block_slots_does_not_panic`.
