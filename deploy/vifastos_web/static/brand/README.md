# ViFastOs — bộ nhận diện

Logo cho sản phẩm **ViFastOs** (dùng cho `os.vifast.org`), cùng hệ với ViFastKey/ViFastTts.

## Ý nghĩa hình

- **Nền đỏ + sao vàng**: Việt Nam.
- **Ba vệt ngang**: tốc độ (Fast).
- **Hai hình lục giác lồng nhau + lõi tròn**: *microkernel* — một lõi nhỏ nằm trong các vành
  bảo vệ (mô hình capability: mọi quyền đều phải đi qua kernel).

## Tệp

| Tệp | Dùng cho |
|---|---|
| `vifastos-icon.svg` | favicon, app icon |
| `vifastos-lockup.svg` | tiêu đề nền sáng |
| `vifastos-lockup-cream.svg` | tiêu đề nền tối |
| `vifastos-icon-{16,32,180,192,512}.png` | favicon PNG, apple-touch-icon, PWA |
| `site.webmanifest` | manifest PWA |
